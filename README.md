# From Excel to Power BI: Comparative Data Analysis Journey

This project explores a **fictitious Global Electronics Retail dataset**, comparing traditional Excel analysis with advanced Power BI business intelligence. It demonstrates how data cleaning, modeling, DAX calculations, and visualization evolve from Excel to Power BI to deliver **interactive dashboards** and actionable insights.

## 🛠 Tools & Techniques
- **Excel:** Power Pivot, Power Query, DAX, Data Cleaning, Visualization  
- **Power BI:** Power Query, DAX, Interactive Dashboards, Slicers, Drill-downs  
- **Focus Areas:** Retail Analytics, KPI Analysis, Revenue & Delivery Trends, Average Order Value (AOV)  

## 📈 Key Insights
- 2016: Baseline year, minimal KPI growth.  
- 2017–2019: Consistent positive growth across revenue, orders, and delivery.  
- 2019–2020: Declining KPIs highlight performance downturns.  
- Average Order Value remained stable across store channels.  
- Power BI dashboards enable dynamic comparisons across years, categories, and channels.  

## 🔑 Outcome
- Power BI enhanced interactivity, efficiency, and storytelling of the analysis.  
- Derived strategic insights despite data limitations, estimating AOV by store type.  
- Showcased evolution from foundational Excel skills to scalable business intelligence.
